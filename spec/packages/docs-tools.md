# `@workspace/docs-tools` — docs index generator and checker

Path: `packages/docs-tools`. Node-only CLI + library that validates every
Markdown file under `docs/` (frontmatter schema, folder rules, links,
tables, length) and generates the three `INDEX.md` files from
frontmatter. A second module checks that the DES-044 parity checklist
only names e2e test titles that exist. Human-facing rules for writing docs
live in `docs/README.md` (DOC-001); this spec covers the tool.

No `exports` / `main`: only used through the `docs` script. Root
`package.json` wires it:

```json
"lint": "turbo lint && pnpm docs:check",
"docs:index": "pnpm -s --filter @workspace/docs-tools run docs index",
"docs:check": "pnpm -s --filter @workspace/docs-tools run docs check"
```

So `pnpm lint` fails when docs are invalid or an index is stale. Root
`.prettierignore` lists `docs/INDEX.md` and `docs/*/INDEX.md`: generated
indexes are emitted unpadded and must not be reformatted (DES-007).

## cli.ts

Usage comment: `tsx src/cli.ts index|check [docsDir]`.

1. `mode = argv[2]`; if not `"check"` or `"index"`: stderr `usage: docs
index|check [docsDir]`, exit **2**.
2. `docsDir = resolve(argv[3] ?? resolve(import.meta.dirname,
"../../../docs"))` (repo `docs/` by default).
3. `{ docs, errors } = run(docsDir, mode)`.
4. Errors: stderr `docs: <n> problem(s)` then each error on its own line
   indented two spaces; exit **1**.
5. Success: stdout `docs: <n> docs ok` plus `, indexes written` in index
   mode; exit 0.

## docs.ts

### Constants

```ts
export const MAX_LINES = 300
export const GENERATED =
  "<!-- Generated by `pnpm docs:index` from frontmatter. Do not edit. -->"
```

Sections (`SectionName = "" | "designs" | "backlogs"`):

| Key        | prefix | title    | holds                                              | types                       | statuses                           |
| ---------- | ------ | -------- | -------------------------------------------------- | --------------------------- | ---------------------------------- |
| `""`       | `DOC`  | Guides   | guides about the docs themselves                   | `guide`                     | `active`                           |
| `designs`  | `DES`  | Designs  | direction docs, system designs and UI instructions | `direction`, `design`, `ui` | `draft`, `active`, `deprecated`    |
| `backlogs` | `BL`   | Backlogs | chunked work items, one per file                   | `backlog`                   | `todo`, `doing`, `blocked`, `done` |

Exported as `SECTIONS: Record<SectionName, Section>` with `Section =
{ prefix, title, holds, types: readonly string[], statuses: readonly
string[] }`.

### Frontmatter schema (zod 4)

```ts
const id = z.string().regex(/^(DOC|DES|BL)-\d{3}$/, "must look like DES-001")
const base = {
  id,
  title: z.string().min(1),
  status: z.string(),
  summary: z
    .string()
    .min(1)
    .max(140)
    .refine((s) => !s.includes("\n"), "one line"),
  tags: z.array(z.string().regex(/^[a-z0-9-]+$/, "lowercase words")).min(1),
  related: z.array(id),
  updated: z.string().regex(/^\d{4}-\d{2}-\d{2}$/, "must be YYYY-MM-DD"),
}
export const frontmatterSchema = z.discriminatedUnion("type", [
  z.strictObject({
    ...base,
    type: z.enum(["guide", "direction", "design", "ui"]),
  }),
  z.strictObject({
    ...base,
    type: z.literal("backlog"),
    priority: z.enum(["P0", "P1", "P2"]),
    depends: z.array(id),
  }),
])
export type Frontmatter = z.infer<typeof frontmatterSchema>
export type Doc = Frontmatter & { file: string; section: SectionName }
export type Result = { docs: Doc[]; errors: string[] }
```

`strictObject` makes unknown keys errors. `status` is free text in the
schema; per-section values are checked later. `updated` must be a YAML
**string** (`2026-11-20` unquoted parses as a string with the `yaml`
package's default core schema).

### Helpers

- `walk(dir)`: recursive `readdirSync(withFileTypes)`; collects files
  ending `.md` (other files, e.g. `docs/demos/*.mp4`, are ignored).
- `countLines(text)`: `text.split("\n").length - (endsWith("\n") ? 1 :
0)`.
- `parseFrontmatter(text)`: matches `/^---\n([\s\S]*?)\n---\n/`.
  - No match → `{ ok: false, errors: ["missing frontmatter"] }`.
  - YAML parse error → `frontmatter is not valid YAML: <first line of
message>`.
  - Schema failure → one error per zod issue:
    `<issue.path.join(".") || "frontmatter">: <issue.message>` (e.g.
    `id: must look like DES-001`, `updated: must be YYYY-MM-DD`, an
    unrecognized-key issue mentioning `extra`, a missing `priority` for
    backlogs).
  - Success → `{ ok: true, meta }`.
- `tableErrors(text)`: GFM table lint.
  - Fenced code: lines are blanked while inside a ` ``` ` fence (the
    fence lines themselves too), so diagrams are ignored.
  - `cols(line) = line.replace(/\\\|/g, "").split("|").length - 2`
    (escaped pipes don't count).
  - A table starts at a line beginning `|` whose previous line does not
    begin `|`. Its next line must match `/^\|( *:?-+:? *\|)+$/` and have
    the same column count, else
    `table at line <i+1> has no valid separator row`.
  - Each following `|` line (from the third) must have the same count,
    else `table row at line <j+1> has <n> cells, want <want>`.

### loadDocs(docsDir): Result

`root = dirname(docsDir)`; every error is
`<path relative to root>: <message>` (so paths read `docs/designs/…`).
For each `.md` file under `docsDir`:

1. Over 300 lines → `<n> lines, max 300`.
2. Links: every `](target)` (regex `/\]\(([^)\s]+)\)/g`); skip targets
   matching `/^[a-z]+:/` (URLs, `mailto:`) or starting `#`; otherwise the
   path before `#` must exist relative to the file → `broken link:
<target>`.
3. Table errors (above).
4. Files named `INDEX.md` (root or any folder) stop here.
5. Section: `rel` path split on `/`; two parts → section = first part,
   one part → `""`. More than two parts or an unknown folder →
   `docs live in docs/, docs/designs/ or docs/backlogs/ only` (skip).
6. Frontmatter errors are reported and the file is skipped.
7. `id must start with <PREFIX>- in this folder`.
8. Unless the file is `README.md` at the root: file name must start with
   `<id lowercased>-` → `file name must start with des-001-`.
9. `type must be one of <types joined ", ">` (so a `direction` doc in
   backlogs fails).
10. `status must be one of <statuses joined ", ">`.
11. Backlogs need a line exactly `## Done when` → `backlog needs a "##
Done when" section`.
12. Accepted docs are pushed as `{ ...meta, file, section }`.

Cross-doc checks after the loop: `duplicate id <ID>` (reported on the
later file), `related <ID> not found`, and for backlogs `depends <ID> is
not a backlog` (also when the id doesn't exist).

### Index rendering

Shared: `cell(s)` escapes `|` as `\|`; `link(d, from) =
[<cell(title)>](<relative(from, d.file)>)`; rows sorted by `id`
(`localeCompare`).

**Section index** (`docs/designs/INDEX.md`, `docs/backlogs/INDEX.md`):

```
<GENERATED>

# <Title> index

Holds <holds>. Back to [docs index](../INDEX.md).

<header>
<rows>
```

(ends with a single `\n` after the last row). Headers:

- designs: `| ID | Type | Status | Title | Summary | Tags |` and `| --- |
--- | --- | --- | --- | --- |`; row `| <id> | <type> | <status> |
  <link> | <summary> | <tags joined ", "> |`.
- backlogs: `| ID | Status | Pri | Depends | Title | Summary | Tags |` and
  seven `---`; row `| <id> | <status> | <priority> | <depends joined ",
" or "-"> | <link> | <summary> | <tags> |`.

**Root index** (`docs/INDEX.md`), lines joined with `\n`:

```
<GENERATED>

# Docs index

Start here. Then open one section index, then only the doc you need.
Schema and retrieval rules: [README.md](README.md).

For direction (vision, architecture, decisions, roadmap) read these first.   ← only if any type=direction docs

| ID | Direction | Summary |
| --- | --- | --- |
| <id> | <link from docs/> | <summary> |   (one per direction doc, sorted by id)

| Section | Index | Size | Holds |
| --- | --- | --- | --- |
| Designs | [designs/INDEX.md](designs/INDEX.md) | <n> docs | <holds> |
| Backlogs | [backlogs/INDEX.md](backlogs/INDEX.md) | <n> docs, <k> open | <holds> |

| ID | Guide | Summary |
| --- | --- | --- |
| <id> | <link> | <summary> |   (docs in section "")
                                ← trailing empty line, so file ends "\n"
```

`open` = backlogs whose status is not `done`. Direction docs appear in
both the root list and the designs table; non-direction designs appear
only in the designs table.

`renderIndexes(docs, docsDir)` returns `{ [absPath]: text }` for the three
files.

### run(docsDir, mode)

`loadDocs`, then for each rendered index: `index` mode writes it (even
when there are validation errors); `check` mode adds
`<rel path>: stale, run \`pnpm docs:index\``when the file is missing or
differs byte-for-byte. Returns`{ docs, errors }`.

## des044-e2e-ids.ts (BL-216)

Keeps `docs/designs/des-044-mock-parity-checklist.md` honest: rows marked
`app` or `drop` must cite a real Playwright test title. Not wired into
the CLI; enforced by its vitest (`pnpm test`).

- `ROOT = resolve(dirname(fileURLToPath(import.meta.url)), "../../..")`.
- Row regex:
  `/^\|\s*[A-Z]{2}-\d+\s*\|[^|]+\|\s*(app|partial|missing|drop)\s*\|\s*`?([^`|]*)`?\s*\|/`(id like`DK-01`, an item cell, a status cell, a test-id cell optionally
  in backticks).
- `requiredDes044TestIds(markdown): { status: "app" | "drop"; testId:
string }[]`: only `app`/`drop` rows whose trimmed test id is non-empty
  and not `—`.
- `collectE2eTitles(testsDir): Map<string, Set<string>>`: for each
  `*.spec.ts` (non-recursive), all titles from
  `/\btest\(\s*(["'])([^"'\\]*(?:\\.[^"'\\]*)*)\1/g` (single or double
  quotes; template literals not matched), with `\'` / `\"` unescaped.
  `test.describe(` is not matched (`\btest\(` needs `(` right after).
- `missingDes044TestIds(markdown, testsDir): string[]`: test id must be
  `<file> › <title>` (separator `" › "`, U+203A); no separator →
  `<testId> (bad format)`; missing file or title → the test id.
- `checkDes044AgainstRepo(root = ROOT)`: reads the checklist and
  `apps/e2e/tests`; `{ ok: true }` or `{ ok: false, missing }`.

## Tests (vitest)

`docs.test.ts` builds a temp `docs/` with `designs/des-001-overview.md`
and a `README.md` guide (`DOC-001`) and asserts: valid parse keeps
quoted colons; precise schema errors (`id: must look like DES-001`,
`updated: must be YYYY-MM-DD`, unknown key `extra`); backlogs need
`priority`; index then check passes and the designs row reads `| DES-001
| design | active | [Overview](des-001-overview.md) |`; direction docs
are listed in the root index above the section table and other designs
are not; a direction doc in backlogs → `type must be one of`; stale index
→ `designs/INDEX.md: stale`; `related DES-404 not found` and `broken
link: nope.md`; `lines, max 300`; `duplicate id DES-001` and `file name
must start with des-001-`; table cases (escaped pipe OK, fenced pipes
ignored, missing separator and ragged row each one error).

`des044-e2e-ids.test.ts`: parses only app/drop rows with ids; reports a
missing title from a temp spec dir; passes against the real repo; accepts
single- and double-quoted titles.
